## 🔬 Current Project

I'm currently using my completed thesis project, a Java/Spring Boot payment system with a Python-based fraud detection service, as the foundation for a separate learning experiment.

The original thesis project is now being used in Payment System — Understanding Spring by Removing It.

The experiment progressively removes Spring mechanisms from the existing application and replaces them with explicit Java implementations.

The goal is not to recreate Spring, but to understand what happens underneath abstractions such as:
- Dependency Injection
- RestTemplate
- JdbcTemplate
- Spring MVC
- Configuration and Application Context

The experiment is developed on the develop-no-spring branch, while main keeps the original Spring-based implementation.
